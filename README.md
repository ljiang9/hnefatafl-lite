# hnefatafl-lite

简化版 **Hnefatafl（维京棋）**：11×11 不对称围攻棋，攻方 24 子围剿，守方 12 子护送国王逃往角落。纯 Python 标准库，零依赖。

## 玩法

- **攻方（●）先手**，目标：四面包围吃掉国王（♔）。
- **守方（○）**目标：把国王送到任意一个角落。
- 走法：横竖走任意格（车式），不可跳子。
- **夹吃**：敌子被两枚己子（或己子 + 空王座/空角落）在正交方向夹住即被吃。
- **国王**：需**四面**被攻方包围才被吃；只有国王能进入/穿过王座与角落。
- 一方无子可走判负；三次重复局面或 600 半回合判和。

## 用法

```bash
python3 -m hnefatafl_lite                 # 人机对弈（终端交互）
python3 -m hnefatafl_lite --auto          # AI 对 AI 演示 10 局
python3 -m hnefatafl_lite --auto --games 20 --seed 7 --verbose
```

交互输入格式：`3,5>3,8`（起点>终点），`q` 退出。

## AI 说明

双方都是 1 步贪心 AI：

- 攻方：吃子优先，其次压缩国王活动空间，并**重罚"走完后王下一步能到角落"的走法**（封堵角落）。
- 守方：吃子优先，其次让国王接近角落。

## 诚实局限

- **规则是简化版**：真实 Hnefatafl 各地规则本就不同（本项目取"角落逃脱、四面吃王、王座/角落作颚"的常见组合），不可当正史规则。
- 棋盘边沿不算夹吃的"颚"；国王贴边时不判被围。
- AI 只是 1 步贪心，不做深层搜索；熟悉棋理的人类通常能赢。
- 文本棋盘，无图形界面/存档/悔棋；Python 3.10+。
